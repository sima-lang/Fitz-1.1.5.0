# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.0.0]

### Добавлено
- Команда состояния («состояние», «мониторинг», «статус системы»): ЦП, ОЗУ, наличие API-ключа (только «задан/не задан»), размер `data/`, число DLC.
- Поиск по истории чата: «найди в истории <слово>».
- Раздельные логи по модулям через `core/logger.py`: `voice.log`, `brain.log`, `ui.log`.
- `requirements.lock` с точными версиями прямых зависимостей (проверено на Python 3.12.6).
- README на русском и английском, файл LICENSE (MIT).
- Тесты: версия, логи модулей, команды состояния и истории, SSRF через редирект, проверка всех адресов хоста.

### Исправлено
- **SSRF через редирект** в `security/safe_links.py`: каждый шаг редиректа проверяется до запроса; раньше запрос к внутреннему адресу выполнялся, а проверка шла после.
- **IPv6 в проверке адресов**: проверяются все адреса хоста, а не только первый IPv4.
- **Удаление файлов** в `vision/super_vision.py`: удаляются только скриншоты портала (кеш GNOME и `screenshot*` в temp). Раньше удалялся любой путь из ответа портала.
- **Атомарная запись JSON**: `core/utils.atomic_write_json` используется в настройках, профиле, памяти (`brain`), истории чата и `soul`. При сбое старый файл сохраняется.
- **Ключ API из окна настроек** применяется при запуске, если `.env` его не задаёт. Раньше после перезапуска ключ мог не подхватываться.
- **Сообщения в логе** в `ui_pyqt.py` описывают действие вместо вводящей в заблуждение «Import/submodule load skipped».
- **Хеш изображения**: sha256 вместо md5 (функция нигде не вызывается).
- **`mss.MSS`** вместо устаревшего `mss.mss` в `core/tools.py`.
- **Тесты**: `mkstemp` вместо `mktemp`; тестовый скриншот во временном каталоге, а не в общем `/tmp`.
- **Ограничение файловых команд**: `_ALLOWED_ROOTS` сужен до Рабочего стола, Документов, Загрузок, Изображений и корня проекта. Раньше доступна вся домашняя папка, включая `~/.ssh` и `~/.gnupg`.

### Удалено
- `security/anti_theft.py`: модуль не обнаруживал вторжений, но генерировал и записывал поддельные данные. Команды «статус антивора» и «кто стучался» теперь сообщают, что функция отключена.
- Модуль DLC «greed» и ссылки на него.
- `get_token.py` — утилита из другого проекта, не относилась к Фитцу.
- Кеш сборки `godot_client/.godot/` из репозитория.

### Известные проблемы
- Команда «дневник» отвечает «нет модуля intelligence», хотя модуль есть: ошибка роутера команд.
- Фразы «запомни что у меня кот» и «что ты знаешь» не распознаются.
- DNS-rebinding в проверке ссылок не закрыт полностью.
- Голос, Live2D, окно чата и ответы языковой модели не проверены вручную в этой версии.
- Закрытие окон по имени на Wayland требует GNOME-расширения и перелогина.

### Не сделано
- Потоковый вывод ответов.
- Подтверждение перед закрытием нескольких окон.
- Smoke-тест импорта модулей в CI с заглушками тяжёлых зависимостей.
- Ручной запуск GUI перед релизом.
