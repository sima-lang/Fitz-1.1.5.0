# Фитц — клиент на Godot 4 (прототип)

Визуальный клиент, который отображает состояние Фитца. Мозг остаётся в `ui_pyqt.py`,
Godot только показывает состояние, которое приходит по WebSocket.

## Запуск

1. Установи Godot 4.2 или новее (`godot` в PATH).
2. Установи пакет `websockets` (если ещё не стоит): `pip install websockets`.
3. Запусти Python-приложение:
   ```
   python ui_pyqt.py
   ```
   В консоли должно появиться `✅ мост к Godot: ws://127.0.0.1:8765`.
4. В другом терминале запусти клиент:
   ```
   godot --path godot_client/
   ```

Клиент подключается к `ws://127.0.0.1:8765` и сам переподключается, если Python-приложение перезапустили.

## Состояния

| state   | Что означает                    | Цвет      |
|---------|---------------------------------|-----------|
| `calm`  | спокойствие (по умолчанию)      | синий     |
| `think` | думает, идёт запрос к модели    | фиолетовый|
| `talk`  | говорит (голос воспроизводится) | зелёный   |
| `error` | ошибка                          | красный   |
| `joy`   | радость (успешный ответ)        | жёлтый    |

Сообщение от сервера: `{"state": "think"}`.

## Что где

- `project.godot` — настройки проекта (окно 320×360, OpenGL Compatibility).
- `main.tscn` — сцена: заглушка-спрайт (`ColorRect`), подпись состояния и строка статуса связи.
- `main.gd` — WebSocket-клиент и смена состояний с плавным переходом.

## Ограничения прототипа

- Вместо спрайта — цветной квадрат. Настоящий персонаж добавляется заменой `Fitz`.
- Состояние `talk` выставляется по флагу `voice.is_speaking`, поэтому совпадает с реальной речью.
- Если Python-приложение не запущено, клиент просто ждёт подключения и показывает статус.
